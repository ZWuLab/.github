# ZWuLab

Statistical software from the research group of
[Zheyang Wu](https://users.wpi.edu/~zheyangwu/), Professor of Mathematical Sciences,
Worcester Polytechnic Institute.

## Statistics — combining dependent evidence

Methods for combining statistical evidence — many p-values, tests, or signals into one
calibrated inference — serving meta-analysis and large-scale multiple testing across fields.

| Package | CRAN | What it does |
|---|---|---|
| [TFisher](https://github.com/ZWuLab/TFisher) | [CRAN](https://cran.r-project.org/package=TFisher) | Optimal thresholding Fisher's p-value combination (a required import of `metap`) |
| [GFisher](https://github.com/ZWuLab/GFisher) | [CRAN](https://cran.r-project.org/package=GFisher) | Generalized Fisher's combination tests under dependence |
| [SetTest](https://github.com/ZWuLab/SetTest) | [CRAN](https://cran.r-project.org/package=SetTest) | Group testing: Higher Criticism, Berk–Jones, phi-divergence procedures |
| [Qapprox](https://github.com/ZWuLab/Qapprox) | [CRAN](https://cran.r-project.org/package=Qapprox) | Tail probabilities of quadratic forms of Gaussian variables |
| [DPComb](https://github.com/ZWuLab/DPComb) | [CRAN](https://cran.r-project.org/package=DPComb) | Discrete p-value combination tests |

## Genomics — the GLOW suite

| Repository | What it does |
|---|---|
| [GLOWr](https://github.com/ZWuLab/GLOWr) | GLOW methodology for integrative variant-set association analysis in whole-genome sequencing |
| [GLOWpipeline](https://github.com/ZWuLab/GLOWpipeline) | Orchestration for genome-wide GLOW scans: chunking, SLURM arrays, aggregation |
| [GLOWanalyses](https://github.com/ZWuLab/GLOWanalyses) | Runnable end-to-end workflow templates, configs, and batch scripts |
